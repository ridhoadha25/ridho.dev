# M. Ridho Adha - Neo-Brutalism Portfolio

Selamat datang di *repository* portofolio pribadi saya! Website ini dirancang dengan gaya **Neo-Brutalism**, menampilkan desain yang berani, kontras tinggi, dan struktur garis-garis tegas yang mencolok.

## Fitur Utama
- 🌗 **Gaya Neo-Brutalism**: Bayangan solid (*hard shadows*), batas garis tebal (*thick borders*), dan kombinasi warna yang cerah.
- 🌐 **Dwi-Bahasa (ID/EN)**: Terintegrasi dengan fitur peralihan bahasa otomatis menggunakan React Context API.
- ⚡ **Performa Cepat**: Dibangun dengan Vite + React untuk waktu muat (*loading*) yang sangat cepat.
- 📱 **Responsif**: Tampilan tetap optimal mulai dari layar *smartphone* hingga *desktop*.
- 🖼️ **Animasi Micro**: Dilengkapi efek kursor unik, elemen yang melayang, dan teks berjalan (*marquee*).

## Teknologi yang Digunakan
- **React (Vite)**
- **Tailwind CSS v4**
- **Lucide-React** (untuk Ikon)

## Cara Menjalankan Secara Lokal

1. **Pastikan Node.js sudah terpasang** di komputer Anda.
2. **Klon atau unduh** proyek ini.
3. Buka terminal di dalam *folder* proyek dan jalankan perintah:
   ```bash
   npm install
   ```
4. Setelah instalasi selesai, jalankan server *development*:
   ```bash
   npm run dev
   ```
5. Buka tautan yang muncul di terminal (biasanya `http://localhost:5173`) di *browser* Anda.
